# Выпускной: моя история с ИИ

Скилл для подготовки личной презентации выпускника НейроШтаба и истории результатов внедрения ИИ-агентов.

Начинает с разговора: что изменилось, какие задачи стали быстрее, что человек создал или впервые смог сделать и какой результат считает главным. Затем проверяет фактуру, согласовывает содержание, собирает реальные скриншоты и делает презентацию.

## Что получится

- Сильная история конкретного человека вместо отчёта о коммитах и количестве агентов.
- Сравнение до/после с учётом проверки и правок, без выдуманной экономии.
- Согласованные результаты, честный статус прототипов и понятный личный вклад.
- Реальные кадры продуктов, документов или примеров работы.
- Живые тексты в авторском стиле человека, без AI-штампов и длинных тире.
- Интересная подача через эпизоды, детали и визуальные решения, без придуманных фактов.

По умолчанию создаёт переносимую HTML-презентацию и краткие заметки выступающего. Если нужен другой формат, укажите его в запросе. Возможность снимать скриншоты зависит от инструментов ассистента; без браузера он запросит готовые кадры и честно обозначит ограничения.

## Установка

Папка с `SKILL.md` и `references/` должна оставаться целой. Выберите каталог своего ассистента.

Для Claude Code:

```sh
git clone https://github.com/rusanovproject-dotcom/graduation-story.git ~/.claude/skills/graduation-story
```

Для Codex:

```sh
git clone https://github.com/rusanovproject-dotcom/graduation-story.git ~/.codex/skills/graduation-story
```

Если каталог уже существует, не клонируйте поверх него. Сначала проверьте установленную версию и свои изменения. Начните новую сессию, чтобы ассистент перечитал каталог скиллов.

## Запуск

> Используй graduation-story. Подготовим мою презентацию на выпускной. Начни с разговора о том, что изменилось после внедрения ИИ-агентов.

Можно отвечать свободно и по частям. Скилл уточняет факты небольшими порциями, сохраняет рабочую память рядом с презентацией и согласовывает точные формулировки до дизайна.

## Границы

Не предназначен для недельного план-факта, коммерческой презентации продукта клиенту или презентации программы курса. Не публикует результаты и не отправляет их в группу без просьбы владельца. Данные учеников и готовые презентации храните в своём рабочем каталоге, не в этом репозитории.

## Проверки

Структура пакета прошла локальный валидатор. Диалоговые правила проверены на синтетических сценариях и независимым ревью. Полная сборка презентации и съёмка реального продукта в этих проверках не выполнялись. Последняя правка авторского голоса проверена чтением и валидатором структуры.
